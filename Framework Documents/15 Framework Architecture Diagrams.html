FoodHub Framework Architecture Diagrams

Readable architecture diagrams for architects, developers, QA leads, and management.

1. Framework Component Architecture

The console is the user-facing command center. It launches services/tests, opens reports, toggles live AI, and opens framework documents. Firebase and Firestore provide shared metrics and live AI configuration support.

2. Observability Data Flow

Local and CI runs push metrics into the same Firebase-backed observability path, then dashboard generation pulls the shared snapshot for trend and route/status analysis.

3. Live AI Analysis Flow

When live AI is off, the same workbook still populates using deterministic fallback logic. When live AI is on, DeepSeek responses are normalized into stable workbook columns.
